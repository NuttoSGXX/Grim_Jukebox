# Grim Jukebox

เครื่องเล่นแผ่นเสียงสำหรับ Foundry VTT (V13–V14) ในซีรีส์ Grim — เปิดเพลงจากลิงก์ YouTube หรือไฟล์เสียงในเครื่องให้ผู้เล่นทุกคนได้ยินพร้อมกัน โดยไม่ต้องดาวน์โหลดเพลง

## ติดตั้ง
วาง Manifest URL ใน Foundry → Add-on Modules → Install Module

```
https://github.com/NuttoSGXX/Grim_Jukebox/releases/latest/download/module.json
```

ตอนสร้าง Release ให้แนบ 2 ไฟล์: `module.json` และ `module.zip`
(ถ้าชื่อ repo ไม่ใช่ `Grim_Jukebox` ให้แก้ 3 บรรทัด `url` / `manifest` / `download` ใน `module.json` ก่อน)

## วิธีใช้ (DM)
1. กด **New playlist** สร้างเพลย์ลิส เช่น `Music`, `Ambience` — เพลย์ลิสละ 1 ช่องเสียง เล่นซ้อนกันได้
2. กด **+** ที่หัวเพลย์ลิสเพื่อเพิ่มเพลง: วางลิงก์ YouTube หรือกด Browse เลือกไฟล์ในเครื่อง แล้วตั้งชื่อ (เว้นว่าง = ใช้ชื่อจาก YouTube), Loop, Fade in / Fade out (ms), ความดัง %
3. กด ▶ หน้าเพลงเพื่อเล่นให้ทุกคน เปลี่ยนเพลงในเพลย์ลิสเดียวกันจะ crossfade ให้เอง
4. **คลิกที่เข็ม** = ยกเข็ม/วางเข็ม: หยุดทุกช่องของทุกคน (เฟดออกตามค่าที่ตั้ง) และกดอีกครั้งเพื่อเล่นต่อจากจุดเดิม
5. ปุ่มบนหัวเพลย์ลิส: สุ่มเพลง, วนทั้งเพลย์ลิส, แก้ไข / ปุ่มบนแถวเพลง: วนเฉพาะเพลงนั้น, แก้ไข

## ฝั่งผู้เล่น
- เห็นเครื่องเล่นแผ่นเสียง แผ่นหมุนด้วยภาพปกคลิป มีแถบเสียง 1 แถบต่อช่องที่กำลังเล่น
- แถบเสียงเริ่มที่ค่าที่ DM ตั้ง ปรับได้เฉพาะเครื่องตัวเอง และดันเกินค่าที่ DM ตั้งได้
- ลากไปวางมุมไหนก็ได้ (จำตำแหน่ง) และย่อเป็นแผ่นเสียงเล็กได้
- เข้าห้องทีหลังหรือกด F5 เพลงจะเล่นต่อที่ตำแหน่งเดียวกับคนอื่น
- ปุ่ม YouTube บนเครื่องเล่น = เปิดดูตัวเล่น YouTube จริง ใช้กดข้ามโฆษณาได้

## ข้อจำกัดของ YouTube
- คลิปที่เจ้าของปิดการฝัง คลิปจำกัดอายุ หรือบล็อกบางประเทศ เล่นไม่ได้ (DM จะเห็นแจ้งเตือน)
- โฆษณาเป็นของ YouTube โมดูลปิดให้ไม่ได้ — ดูหัวข้อถัดไป
- การวนเพลงจาก YouTube มีช่องว่างสั้น ๆ ตรงรอยต่อ ถ้าต้องการเนียนสนิทใช้ไฟล์ในเครื่อง
- ตัวเล่น YouTube ถูกซ่อนไว้ตามปกติ ซึ่งไม่ตรงกับเงื่อนไขการใช้ตัวเล่นฝังของ YouTube ที่ให้แสดงตัวเล่นไว้ ถ้าต้องการให้ตรงเงื่อนไขให้เปิดหน้าต่าง YouTube ค้างไว้

## เรื่องโฆษณา
- ผู้เล่นที่ล็อกอิน YouTube Premium ในเบราว์เซอร์เดียวกันจะไม่เจอโฆษณา
- เลือกคลิปจากช่องที่ไม่เปิดสร้างรายได้ (เพลงฟรีลิขสิทธิ์, ช่อง ambience ของ TTRPG หลายช่อง)
- เพลงที่ใช้บ่อยหรือฉากสำคัญ ใช้ไฟล์ในเครื่องแทน
- ถ้าโฆษณาขึ้น: กดปุ่ม YouTube เพื่อข้าม จากนั้นโมดูลจะดึงเพลงกลับมาตรงจังหวะเดียวกับคนอื่น

## ขนาดและแผงเพลย์ลิส
- Settings → Grim Jukebox → Turntable size: 50% (ค่าเริ่มต้น), 65%, 80%, 100% — ตั้งแยกของแต่ละคน
- DM ปิดแผงเพลย์ลิสได้ด้วยปุ่ม × บนหัวแผง และเปิดคืนด้วยปุ่มรายการ (list) ใต้เครื่องเล่น

## ธีม
Settings → Grim Jukebox → Colour theme (DM ตั้ง ใช้กับทุกคน): Black & Red, Black-Grey-White, White & Purple, Black & Blue

## Macro API
```js
const jb = game.modules.get("grim-jukebox").api;
jb.toggleNeedle(); jb.stopAll(); jb.toggleWindow(); jb.resetPosition();
```
